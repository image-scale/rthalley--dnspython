# Goal

## Project
dnspython — a python project.

## Description
A comprehensive DNS toolkit for Python that provides both high-level and low-level access to DNS operations. It supports DNS queries, zone transfers, dynamic updates, TSIG-authenticated messages, EDNS0, and almost all DNS record types. The library works with the Python standard library alone (no external dependencies required for core functionality).

## Scope
- ~30 production source files to implement across core package modules
- ~10 test files to write covering all functionality
- Reproduce core DNS functionality: names, record types, messages, wire format, zones, resolver, updates
